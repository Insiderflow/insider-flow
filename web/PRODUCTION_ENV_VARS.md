# Production Environment Variables

Copy these environment variables to your **Render** web service (or any host running this Next app with the same shape of secrets):

```bash
# Database — Neon gives two URLs in the dashboard:
# - “Transaction” / pooled (host contains `-pooler`): use for DATABASE_URL (runtime).
# - “Direct” / session (no pooler): use for DATABASE_URL_UNPOOLED (migrations only).
# Set DATABASE_URL_UNPOOLED to the Neon **direct** connection string, then use the migrate wrapper below on Render.
DATABASE_URL="postgresql://USER:PASSWORD@YOUR-NEON-POOLER-HOST/neondb?sslmode=require"
DATABASE_URL_UNPOOLED="postgresql://USER:PASSWORD@YOUR-NEON-DIRECT-HOST/neondb?sslmode=require"

# Session Management
SESSION_SECRET="your-32-character-secret-key-here"
INTERNAL_JOBS_SECRET="your_internal_jobs_secret_here"

# Email Service
GRIDSEND_API_KEY="gs_your_api_key_here"
EMAIL_FROM="no-reply@insiderflow.asia"

# Application URLs — keep NEXT_PUBLIC_BASE_URL and NEXTAUTH_URL on the same host users open (e.g. www).
NEXT_PUBLIC_BASE_URL="https://www.insiderflow.asia"
TRUST_PROXY=true

# Google OAuth Credentials
GOOGLE_CLIENT_ID=your_google_client_id_here
GOOGLE_CLIENT_SECRET=your_google_client_secret_here

# NextAuth Configuration
NEXTAUTH_SECRET=your_nextauth_secret_here
NEXTAUTH_URL=https://www.insiderflow.asia

# Stripe Configuration
STRIPE_SECRET_KEY=your_stripe_secret_key_here
STRIPE_WEBHOOK_SECRET=your_stripe_webhook_secret_here
NEXT_PUBLIC_STRIPE_PRICE_MONTHLY=your_monthly_price_id_here
NEXT_PUBLIC_STRIPE_PRICE_YEARLY=your_yearly_price_id_here

# RevenueCat (native App Store / Play subscriptions)
REVENUECAT_SECRET_API_KEY=your_revenuecat_secret_api_key_here
REVENUECAT_WEBHOOK_AUTH=your_revenuecat_webhook_bearer_secret_here
# Optional but recommended when using x-revenuecat-signature verification.
REVENUECAT_WEBHOOK_SECRET=your_revenuecat_webhook_signature_secret_here
# Optional: if set, only this entitlement grants paid status.
REVENUECAT_ENTITLEMENT_ID=pro

# Subscription pipeline alerting (recommended)
# JSON webhook target for operational alerts generated by internal scheduler endpoint:
# /api/internal/jobs/subscription-events/alerts
SUBSCRIPTION_ALERT_WEBHOOK_URL=https://hooks.example.com/subscription-alerts
# Optional threshold tuning:

SUBSCRIPTION_ALERT_DEAD_LETTER_RATE_CRITICAL=0.02
SUBSCRIPTION_ALERT_OLDEST_FAILED_MINUTES_WARN=30
SUBSCRIPTION_ALERT_STALE_PROCESSED_MINUTES_CRITICAL=120
```

**Render “Pre-deploy command”** — do **not** run `npx prisma migrate deploy` with only the pooler URL (Prisma **P1002** advisory lock timeout).

Either:

```bash
cd web && sh scripts/render-migrate-deploy.sh
```

(requires `web/scripts/render-migrate-deploy.sh` to exist in the deployed commit)

Or inline (same behavior, no script file):

```bash
cd web && export DATABASE_URL="${DATABASE_URL_UNPOOLED:-$DATABASE_URL}" && npx prisma migrate deploy
```

If Render **Root Directory** is already `web`, drop the `cd web &&` prefix from whichever command you use.

Runtime traffic still uses pooled `DATABASE_URL`; migrate temporarily uses `DATABASE_URL_UNPOOLED` when set.

## Important Notes

## Scheduler Setup (required for auto-retry + alerts)

The internal subscription pipeline now expects periodic calls to:

- `POST /api/internal/jobs/subscription-events` (auto-replay failed eligible events)
- `POST /api/internal/jobs/subscription-events/alerts` (evaluate thresholds + dispatch notifications)

You can run this with GitHub Actions using `.github/workflows/subscription-jobs.yml`.

Required GitHub repository secrets:

- `INTERNAL_JOBS_BASE_URL` (example: `https://www.insiderflow.asia`)
- `INTERNAL_JOBS_SECRET` (must match backend env `INTERNAL_JOBS_SECRET`)

Manual smoke test from terminal:

```bash
curl -X POST "https://www.insiderflow.asia/api/internal/jobs/subscription-events" \
  -H "authorization: Bearer $INTERNAL_JOBS_SECRET" \
  -H "content-type: application/json" \
  -d '{"limit":20}'

curl -X POST "https://www.insiderflow.asia/api/internal/jobs/subscription-events/alerts" \
  -H "authorization: Bearer $INTERNAL_JOBS_SECRET" \
  -H "content-type: application/json" \
  -d '{}'
```
